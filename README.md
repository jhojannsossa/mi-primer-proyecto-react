🚀 Mi Primera App en React - Testimonios
¡Bienvenido a mi proyecto de testimonios desarrollado con React, Vite, HTML y CSS! Esta aplicación forma parte de mi camino como desarrollador web front-end, mostrando experiencias reales de alumnos y su evolución profesional.

📸 Vista Previa del Proyecto
✨ Características Principales
Componentes Modulares: Estructura limpia basada en componentes reutilizables de React (Testimonio.jsx).

Diseño Atractivo y Coherente: Tarjetas estilizadas con CSS moderno, uso de sombras, bordes redondeados y proporciones de imagen uniformes (object-fit: cover).

Fondo Personalizado: Fondo de pantalla global adaptable y optimizado mediante index.css.

Interactividad y Rendimiento: Desarrollado con Vite para ofrecer una carga ultrarrápida y una experiencia de usuario fluida.

🛠️ Tecnologías y Herramientas Utilizadas
React.js (Biblioteca principal de JavaScript para la interfaz)

Vite (Entorno de desarrollo rápido)

HTML5 (Estructura semántica)

CSS3 (Estilos modernos, Flexbox)

Git & GitHub (Control de versiones)

Vercel (Despliegue y producción)

⚙️ Cómo ejecutar el proyecto localmente
Si deseas clonar y probar este proyecto en tu computadora, sigue estos pasos:

Clona el repositorio:

Bash
git clone https://github.com/jhojannsossa/tu-repositorio.git
Entra a la carpeta del proyecto:

Bash
cd mi-primer-proyecto-react
Instala las dependencias:

Bash
npm install
Inicia el servidor de desarrollo:

Bash
npm run dev
Abre tu navegador e ingresa a http://localhost:5173.

🌐 Enlace en Vivo
Pronto podrás ver este proyecto desplegado y funcionando en producción a través de Vercel.
